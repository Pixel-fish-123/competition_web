# 三角占领 · 比赛说明书

> **适用对象**：参赛选手、裁判。
> **说明**：本说明书为现行比赛规则的唯一正式文本，所有判定以本说明为准。
> 开发者如需实现索引与修改约束，见 `structure.md`；完整算法设计见 `plan.md`。
> 本说明书中不包含任何实现细节，仅描述比赛玩法。

---

## 一、比赛概述

1.1 本比赛为**双阵营对抗制**实时计分赛。两队分别扮演「**防守方**」与「**攻击方**」，在 7 层三角形地图上通过完成音游挑战占领格子、争夺分数与胜利条件。

1.2 **每队 3 名队员**，共 6 人同场竞技。**每名队员同一时间只能进行一个格子的挑战**（每队同时最多有 3 个挑战在进行）。

1.3 单局限时 **25 分钟**。限时内攻击方还可通过 L1 源头的能量机制提前锁定胜局（见第八章）。

## 二、场地与地图

2.1 地图为 7 层三角形金字塔，共 **27 格**：
- 第 1~6 层共 **21 个任务格**：L1（顶端源头，1 格）、L2（2 格）、L3（3 格）、L4（4 格）、L5（5 格）、L6（6 格）；
- 第 7 层 **6 个能源格**（不可占领）。

2.2 相邻关系：三角网格相邻（上下左右）；能源格仅与正上方的 L6 格相邻。

2.3 顶端 **L1 源头**是全图核心：可反复争夺，并附带能量机制（见第八章）。

## 三、赛前准备与开局

3.1 赛前由裁判**导入歌曲库**（至少 25 首、歌名唯一），随后**随机开局**。

3.2 开局时系统自动生成本局任务表：
- 从歌曲库随机抽取 **25 首**，按难度定数删去**最难与最简各 1 首**，余 **23 首**；
- 从 23 首中随机抽取 **20 首**分配任务，按**「中腹高分」模板**落位到 L2~L6（中腹区域承接最高难度，两侧偏低）；
- **L1 最后填充**：从剩余 3 首中选难度定数最高的一首，固定任务分 **+10**。

3.3 **开局瞬间，防守方以 0 分 0 TP 预先占领 L1**（防御姿态）。攻击方首次挑战只要成绩优于 0 分即可夺得 L1，并获得 1 点能量（见 8.1）。

## 四、占领规则

4.1 完成格子对应歌曲的任务要求即可**占领**该格。

4.2 **普通格（L2~L6）占领后归属不可更改**：先到先得，不可覆盖、不可夺回（同阵营重复占领无效）。

4.3 **L1 例外**：L1 可被双方**反复挑战**。挑战须提交成绩（分数必填、TP 可选），判定规则：
- **分数更高**者占领；
- 分数相同则 **TP 更高**者占领；
- 分数与 TP 均相同则维持原持有方不变。

4.4 裁判可**清除**误操作的占领；清除 L1 会连其历史成绩纪录一并重置。

## 五、激活与能源

5.1 攻击方的格子只有与某能源格**连通**（路径上全部为攻击方占领格）才视为「**已激活**」。

5.2 **未激活的攻击方格不计分**，也不享受能源加成。

5.3 已激活的攻击方格按所在连通块获得能源加成，**接触 1 / 2 / 3 / ≥4 个能源格 → 每格 +0 / +1 / +2 / +2**（封顶 +2）。

5.4 **L1 得分豁免激活**：攻击方占领 L1 即计分，与是否激活无关（激活 L1 不再影响胜负，见 8.5）。

## 六、包围机制

6.1 当防守方用己方占领格（或地图边界）将一片「**未占领 + 攻击方未激活**」格**完全围住**时，整片区域**立即变为防守方地块**（其中的未激活攻击方格被「吃掉」）。

6.2 判定要点：
- **攻击方已激活地块、能源格相邻会阻断包围**（该区域不被围）；
- **L1 可位于区域内**，但包围成立时**本身不被转换**；
- 包围**可多次触发**：每次占领变化后自动判定，可反复发生；
- **攻击方持有 L1 期间，包围机制整体失效**；防守方夺回 L1 后恢复。

6.3 通过包围获得的格子以**虚线边框**标示，功能与普通占领格完全相同（计分、参与激活与后续包围均正常）。

## 七、计分方式

7.1 每格总分 = **歌曲难度分（0~10）+ 任务要求分（0~10）**，满分 **20 分**。

7.2 **歌曲难度分**（10 分制，依据 Cytus II 2026 难度表，**只看定数，与歌曲类型 Chaos/Glitch/Hard 无关**；带 `+` 的定数在原等级基础上 +1 分，封顶 10 分）：

|---|---|---|
| ≤3 | 1 | |
| 4 ~ 6 | 2 | |
| 7 ~ 8 | 3 | |

| 15 | 9 | 15+ 为 10 |
| 16 / 16+ | 10 | 封顶 |

7.3 **任务要求分**（10 分制，16 项任务）：

7.4 **L1 固定任务分 +10**；L1 被攻击方占领时实时计入攻击方总分。

## 八、L1 源头与能量机制

8.1 **能量积累**：
- 攻击方占领 L1 **立刻 +1 能量**（含夺回）；
- 攻击方**持有期间每满 2 分钟 +1** 能量。

8.2 防守方夺回 L1 后：已积累能量**保留**、**暂停积累**；攻击方再夺回后从保留值继续积累。

8.3 **能量满 10 点 → 攻击方直接获胜**（L1 能量胜利），防守方当前分数**保留不变**。

8.4 攻击方持有 L1 期间，**包围机制整体失效**（见 6.2）。

8.5 旧版「攻击方激活 L1 即秒胜」规则**已废除**：L1 激活与否不再影响胜负。

## 九、胜负判定

9.1 **L1 能量胜利**：攻击方能量满 10 点 → 攻击方立即获胜。

9.2 **计时结束**：限时 25 分钟耗尽（或裁判手动结束）→ 分数高者胜，同分则**平局**。

9.3 棋盘占满**不自动结算**，仍等待限时结束或裁判手动结束。

## 十、裁判操作

10.1 赛前：导入歌曲库（至少 25 首、歌名唯一）→ 随机开局。
10.2 赛中：记录与录入双方占领、L1 挑战成绩（分数/TP）；可清除误操作；可调整限时。
10.3 赛后：手动结束比赛；导出事件日志存档；保存棋盘截图。

## 十一、选手须知

- 每名队员同一时间只能进行**一个格子**的挑战，注意团队分工；
- 攻击方：优先建立**能源通路**（激活）再占领高分格，并留意 L1 能量与包围的配合；攻击方持有 L1 期间防守方无法发动包围；
- 防守方：善用**包围**（可多次触发）与 **L1 争夺**（夺回即冻结攻击方能量积累）控制节奏；
- 未激活的攻击方格不计分；成绩不满足任务要求时占领无效。
