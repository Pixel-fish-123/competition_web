这份文档用于指导 OpenCode 使用 `ui-ux-pro-max-skill`，为音游比赛网站生成简洁、明亮、未来工业感的 UI。

## 完整提示词

```text
使用 ui-ux-pro-max skill，为一个音游比赛设计网站生成完整设计系统并实现首页。

项目定位：
这是一个面向音游玩家的赛事平台，包含赛事日程、报名入口、选手排名、曲目列表、比赛结果和直播入口。

视觉方向：
希望有未来军事科幻、工业界面和高对比信息设计气质，但不要直接复制任何现有作品的角色、Logo、素材、字体或具体界面。请提取并重新设计这些抽象特征：
- 简洁、明亮、理性
- 白色和浅灰作为主背景
- 深灰文字
- 使用冷蓝、青绿色作为主强调色
- 少量橙黄色作为赛事状态和 CTA 色
- 细边框、切角、编号、网格、数据标签
- 轻微工业感，但整体保持清爽和易读
- 不使用厚重玻璃拟态、紫色渐变、霓虹赛博朋克或大面积黑底

布局要求：
- 首页首屏展示当前主赛事、比赛倒计时
- 桌面端信息密度较高，但层级清晰
- 移动端改为单列布局
- 重要按钮、卡片和导航必须有 hover、focus 和 active 状态
- 保证 WCAG AA 对比度
- 支持 375px、768px、1024px 和 1440px 宽度

交互和动效：
- 使用克制的扫描线、进度条、数字变化和状态切换动画
- 动效时长 150-300ms
- 不要自动播放音乐或大幅视差
- 支持 prefers-reduced-motion

技术要求：
- 使用 Lucide 图标，不要用 emoji
- 先输出设计系统：配色、字体、间距、圆角、按钮、卡片和断点
- 然后实现首页
- 最后检查响应式、可访问性、文字对比度和 UI 反模

这是对现有网站的增量改造，不要重写项目架构，不要更换已有路由和数据接口。
先检查现有组件、主题变量和页面结构，只修改与视觉和交互相关的部分。
保留现有功能，并尽量复用已有组件。式
```
